# Pilot support

FinCompiler is currently an alpha pilot.

Before reporting a problem:

1. Confirm the ZIP SHA-256 matches the value in the README.
2. Extract the entire ZIP before opening `FinCompiler.exe`.
3. Reproduce the problem with the included synthetic demo when possible.
4. Record the step, visible error and expected result.

Use the GitHub issue forms in this repository. Never attach real company files or unredacted screenshots to a public issue.

The most useful workflow feedback describes:

- the manual finance task being replaced;
- the source systems and export types;
- the time normally spent;
- the point where FinCompiler helped or blocked completion;
- what evidence a reviewer needed before trusting the result.
